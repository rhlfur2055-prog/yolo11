# 데이터 증강 전략 (Data Augmentation)

CRNN 한글 교차검증 모델(`plate_ocr_crnn.pth`)의 학습 데이터 구성과 증강 파이프라인.

---

## 핵심 요약

```
실제 132장 ──── 8종 증강 기법 ────► 1,320장 (10× fold)
                                              │
합성 20,647장 (3종 plate type) ───────────────┴── 21,967 학습 샘플
                                                  │
                                          ┌───────┴────────┐
                                          │ 학습/검증 90/10  │
                                          │ 200 epoch       │
                                          │ RTX 4060        │
                                          │ CTC loss        │
                                          └───────┬────────┘
                                                  ▼
                                          검증 정확도 131/132 (99%)
```

---

## 데이터 구성 (3계층)

| 계층 | 수량 | 출처 | 비고 |
|------|------|------|------|
| 실제 사진 | 132 | 직접 촬영/수집 한국 번호판 | seed 데이터셋 |
| 실제 사진 증강 | 1,320 | 132 × 10 fold | augmentation pipeline |
| 합성 데이터 | 20,647 | 폰트 + 배경 + 노이즈 합성 | 신형 1줄 / 구형 2줄 / 영업용 |
| **총 학습 샘플** | **21,967** | | 99% validation 정확도 |

---

## Phase 1 — 실제 사진 증강 (132 → 1,320)

각 실제 사진에 대해 무작위 증강 조합을 적용해 10개 변형 생성.

| 기법 | 파라미터 (추정) | 시뮬레이션 대상 | 한국 번호판 적용성 |
|------|-----------------|----------------|-------------------|
| Rotation | ±10° | 카메라 기울기, 차량 각도 | 핵심 |
| Affine / Shear | shear ±0.1 | 원근 왜곡 (광각 렌즈, 측면 촬영) | 핵심 |
| Scale | 0.8 ~ 1.2× | 차량과 카메라의 거리 변동 | 핵심 |
| Brightness / Contrast | ±20% | 주야간 / 역광 / 그림자 | 핵심 |
| Gaussian blur | σ = 0.5 ~ 2.0 | 모션 블러 (주행 중 촬영) | 적용 |
| Gaussian noise | σ = 5 ~ 15 | 센서 노이즈 (저조도) | 적용 |
| JPEG compression | quality 50 ~ 95 | 저화질 카메라 / 압축 아티팩트 | 적용 |
| HSV jitter | hue ±5%, sat ±10% | 색온도 변동 (백색광 / 형광등 / 햇빛) | 적용 |

**적용 방식 (추정):** 각 원본에 대해 위 기법 중 무작위 K개(K=2~5) 조합을 10번 샘플링.

---

## Phase 2 — 합성 데이터 생성 (20,647)

번호판 텍스트를 정규식 기반으로 생성하고 폰트/배경/노이즈를 합성.

### 텍스트 생성 규칙
- 신형 1줄 (7자리): `\d{2,3}[가-힣]\d{4}`
  - 예: `01나8060`, `123가4567`
- 구형 2줄 (지역명): `[가-힣]{2}\d{2,3}[가-힣]\d{4}`
  - 예: `서울70바9203`, `경기91바6286`
- 영업용: 한글이 `바·사·아·자` 등 영업용 한글 사용

### 합성 변수 (조합 폭발)
| 변수 | 가능 옵션 | 비고 |
|------|----------|------|
| 폰트 | 한국 번호판 전용 (직사각형 고딕) | 신형/구형 폰트 분리 |
| 배경색 | 흰색, 녹색(영업), 노란색(택시) | 3종 |
| 텍스트 색상 | 검정 (대부분), 흰색 (반전) | 2종 |
| 외곽 테두리 | 있음 / 없음 | 2종 |
| 위 모든 증강 (Phase 1) | 동일하게 적용 | 추가 다양성 |

→ 변수 조합으로 20,000+ 샘플 확보 가능.

## 회귀 테스트와의 관계 (정직성)

| 항목 | 학습 데이터 | 회귀 테스트 (`22/`) |
|------|------------|---------------------|
| 출처 | 132 실제 + 20,647 합성 | 12장 close-up 실측 (+ 6장 확장) |
| 증강 적용 | Phase 1 적용 | 증강 없음 — 실측만 |
| 목적 | CRNN 학습 / 검증 | end-to-end 파이프라인 회귀 baseline (smoke) |
| 결과 | 검증 131/132 (99%) | 12/12 (100%) — close-up 케이스만 |

**회귀 테스트의 12장은 모두 `frame_area_ratio ≈ 43%`의 close-up** — YOLO에게 매우 쉬운 케이스. 실제 도로 영상의 detection recall은 별도 검증 필요. README `## 성능` 섹션의 "알려진 측정 공백" 박스 참고.

## 한계와 정직성

| 항목 | 상태 |
|------|------|
| `train_plate_ocr.py` (학습 스크립트) | **5f73323f 커밋에서 정리됨** — 재현 불가능 |
| 정확한 augmentation 라이브러리 | albumentations 추정 — 코드 검증 불가 |
| 정확한 hyperparameter | learning rate, batch size 등 미공개 |
| 합성 데이터 생성 코드 | 미공개 |
| 본 문서의 증강 기법 | 일반적 OCR 학습 패턴 + README 수치 기반 **재구성** |

### 재현하려면

1. 한국 번호판 데이터셋 100~200장 직접 수집
2. albumentations 또는 imgaug로 위 8종 증강 파이프라인 구축
3. 폰트 + 배경 + 텍스트 합성기 작성 (PIL/Pillow)
4. CRNN 학습 코드 (`docs/CODE_TOUR.md` 참고 — `plate_recognition_4k.py:L666+` PlateRecognizer가 CRNN 구조 참조 가능)
