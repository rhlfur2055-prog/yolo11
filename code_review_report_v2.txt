G-3. 탐지 방식 비교

  plate_recognition_4k.py: SAHI 우선 전략

    └─ COCO 폴백: 2단계 (차량 감지 → 번호판 크롭)

  plate_engine_pro.py: 해상도 적응형 직접 추론
    ┌─ 해상도 감지: 4K(1920) / FHD(1280) / HD(960) / SD(640)
    ├─ 직접 YOLO 추론 (적절한 imgsz)

    └─ ROI 필터: 300-800px × 150-700px 하드코딩
    비용: 1 GPU op/프레임 + CPU NMS


G-4. OCR 파이프라인 비교
──────────────────────

  plate_recognition_4k.py: 3-엔진 순차
    1. PaddleOCR (한국어, det=True) → 줄 정렬 → 결합
    2. EasyOCR (2개 언어) → 폴백
    3. Tesseract → 레거시 폴백
    결합: 줄 레벨 정렬, 단순 결합, 기본 신뢰도 평균
    복잡도: ~200줄

  plate_engine_pro.py: 4-엔진 앙상블 + HangulClassifier
    1. CRNN (학습된 한국 번호판 OCR)
    2. PaddleOCR (det=True + 줄 정렬)
    3. EasyOCR (허용문자 필터)
    4. Tesseract (PSM 7, 폴백)
    + 추가 크롭 OCR (2줄 번호판 상/하 분리)
    결합: 위치 기반 분해 투표 (초성-중성-종성)
          자모별 신뢰도 가중
          HangulClassifier 교차검증
    복잡도: ~2000줄

G-6. 추적/상태 관리 비교
──────────────────────

  plate_recognition_4k.py: 상태 머신 (프레임 레벨)
    CaptureState.SCANNING → TRACKING → CAPTURING
    ├─ SCANNING: 프레임 스킵 (기본 2)
    ├─ 감지 → TRACKING
    ├─ 2차 감지 → CAPTURING (버스트 모드)
    ├─ burst_counter ≥ 10 또는 no_detect ≥ 3 → 완료
    └─ 3프레임 쿨다운 → SCANNING 복귀
    결과: 버스트 클러스터별 최적 프레임 선택 (IoU 기반)

  plate_engine_pro.py: PlateTracker (bbox + 텍스트 이중 레이어)
    ├─ IoU 기반 매칭 (threshold=0.30)
    ├─ TTL: 15프레임 미감지 → 트랙 삭제
    ├─ 텍스트 병합: IoU < 0.30이지만 같은 OCR 텍스트 → 트랙 병합
    ├─ 트랙별 투표: text → {count, first_frame, last_frame, best}
    └─ end_frame() 유예 기간: 3프레임 미감지 → consecutive 유지


G-7. 한글 교정 비교
──────────────────

  plate_recognition_4k.py:
    1. correct_ocr_hangul(): 숫자→한글 교정 (_HANGUL_CONFUSE_MAP)
       "2"→"가", "7"→"나" 등
    2. correct_hangul_similarity(): 유사 한글 교환
       "시"→"서", "지"→"저" 등 (무효→유효 방향만)
    3. validate_plate_format(): 엄격한 형식 검사
       신규: \d{2-3}[가-힣]\d{4}, 구형: [지역]{2-3}\d{2}[가-힣]\d{4}
    4. _HANGUL_PLATE_CORRECTION: 100+ 무효→유효 매핑 (AI Hub 기반)
    교정 줄: ~600줄

  plate_engine_pro.py:
    1. PlateValidator._KR_CONFUSION: 20항목 혼동 맵
       "비"→"바", "시"→"서", "지"→"저" 등
    2. HangulClassifier: 크롭 레벨 초성 검증
       ├─ PaddleOCR det=False × 6 전처리 변형
       ├─ 초성 인덱스 추출
       ├─ ㅅ(9)→ㅈ(12): ㅈ 그룹 감지 시
       ├─ ㅁ(6)→ㅂ(7): 구조적 막대 분석 + 밀도
       └─ ≥2 증거 (6 변형 중 과반)
    3. _REGION_CONFUSION_MAP: 구형 번호판 지역명 교정
       "얼리"→"경기", "서올"→"서울" 등
    교정 줄: ~1000줄+
