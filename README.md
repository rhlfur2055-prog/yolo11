# 한국 차량 번호판 자동 인식 시스템 (YOLO11 + PaddleOCR)

> YOLO11x 객체 탐지 + PaddleOCR(한국어 PP-OCRv5) 기반  
> 정적 이미지 **12/12 (100%)** 정확도 달성

## 파이프라인 전체 구조


## best.pt 탐지 과정 — 이미지가 들어가서 좌표가 나오기까지

### Step 1 — 이미지 입력 전처리
```
원본 프레임 (예: 1920×1080, BGR)
        │
        ▼ ① 640×640으로 리사이즈 (YOLO11 기본 입력 크기)
        ▼ ② BGR → RGB 변환
        ▼ ③ 픽셀 정규화: 0~255 → 0.0~1.0  (각 픽셀 ÷ 255)
        ▼ ④ 텐서 변환: (H, W, C) → (1, C, H, W)  배치 차원 추가
        │
        ▼
   best.pt 신경망에 입력
```

### Step 2 — best.pt 신경망 내부 추론
```
640×640 이미지
        │
        ▼
┌─────────────────────────────────┐
│  Backbone (특징 추출)             │
│                                  │
│  Conv Layer 1 → Feature Map     │  ← 큰 물체 감지용 (얕은 층)
│  Conv Layer 2 → Feature Map     │
│  Conv Layer N → Feature Map     │  ← 작은 물체 감지용 (깊은 층)
│  ...총 수십 개 레이어              │
│                                  │
│  "번호판처럼 생긴 패턴이            │
│   이미지 어디어디에 있다"를         │
│   숫자 배열(Feature)로 표현        │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│  Neck — FPN (스케일 통합)         │
│                                  │
│  작은 번호판(원거리) +             │
│  큰 번호판(근거리) 모두 잡기 위해   │
│  다양한 해상도 Feature Map 합치기  │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│  Head (예측 출력)                 │
│                                  │
│  이미지를 격자(Grid)로 나눠서      │
│  각 칸마다 예측:                  │
│  - 이 칸에 번호판 있을 확률        │
│  - bbox 중심 x, y               │
│  - bbox 너비, 높이               │
└────────────┬────────────────────┘
             │
             ▼
   수천 개의 bbox 후보 생성
```

### Step 3 — NMS로 최종 1개 선택
```
신경망 원시 출력 (수천 개):
  bbox1: [100,200,300,250]  conf=0.92
  bbox2: [102,198,305,252]  conf=0.89  ← 거의 같은 위치 (겹침)
  bbox3: [101,201,302,249]  conf=0.87  ← 거의 같은 위치 (겹침)
  bbox4: [500,100,600,150]  conf=0.12  ← 번호판 아님
  ...수천 개...
        │
        ▼ [필터 1] confidence < 0.30 제거
        │
        ▼ [필터 2] NMS (Non-Maximum Suppression)
                   IoU > 0.5 이면 같은 번호판으로 판단
                   → conf 낮은 것 제거, 가장 높은 것만 남김
        │
        ▼
  최종 출력: bbox=[100,200,300,250]  conf=0.92
```

### Step 4 — 좌표 역변환 (640 → 원본 크기)
```
YOLO 출력 (640×640 기준):  x1=100, y1=200, x2=300, y2=250

원본이 1920×1080이었다면:
  x 스케일 = 1920 / 640 = 3.0
  y 스케일 = 1080 / 640 = 1.6875

원본 좌표 변환:
  x1 = 100 × 3.0    = 300
  y1 = 200 × 1.6875 = 337
  x2 = 300 × 3.0    = 900
  y2 = 250 × 1.6875 = 422

최종 출력: [300, 337, 900, 422, 0.92]
            좌상x 좌상y 우하x 우하y 신뢰도
```

### Step 5 — 마진 추가 후 ROI 크롭
```python
w = x2 - x1
h = y2 - y1

# 번호판 가장자리 잘림 방지 — 35~40% 마진 추가
x1 = max(0, x1 - w * 0.35)
x2 = min(frame_width,  x2 + w * 0.35)
y1 = max(0, y1 - h * 0.40)
y2 = min(frame_height, y2 + h * 0.40)

roi = frame[y1:y2, x1:x2]  # 원본 프레임에서 크롭
# → 이 roi가 PaddleOCR에 전달됨
```

## best.pt vs PaddleOCR — 역할 분담

```
best.pt   →  "300~900px 사이에 번호판 있음" (위치만)
                          │
                          ▼
PaddleOCR →  그 영역 잘라서 "180라9396" 글자 읽기

best.pt 없으면  → 어디를 잘라서 OCR에 넘겨야 할지 모름
PaddleOCR 없으면 → 번호판 위치는 알지만 번호를 읽을 수 없음
```

## 핵심 알고리즘 상세

### best.pt — YOLO11x 번호판 탐지기
- **역할**: 프레임에서 번호판이 있는 위치(bbox)만 찾는다
- **모델**: YOLO11x fine-tuned on Korean license plates
- **성능**: mAP@50 = 98.4%, 탐지 신뢰도 임계값 0.30
- **출력**: `[x1, y1, x2, y2, confidence]` — 텍스트 인식은 하지 않음
- **2-stage**: 1단계에서 번호판 탐지, 2단계에서 차량 전체 탐지 후 교차 검증

### 18가지 전처리 파이프라인
각 전처리는 독립적으로 PaddleOCR에 입력되어 다양한 조건에서 최적 인식을 끌어낸다:

| 번호 | 전처리 방식 | 대상 조건 |
|------|------------|---------|
| 1~3 | CLAHE (클립 1.5/3.0/5.0) | 저대비, 야간 |
| 4~5 | 이진화 (Otsu, 적응형) | 그림자, 역광 |
| 6~7 | 컬러 강조 (HSV, LAB) | 노란/초록 번호판 |
| 8~9 | 샤프닝 + 노이즈 제거 | 블러, 저화질 |
| 10~12 | 회전 보정 (-5도, 0도, +5도) | 기울어진 촬영 |
| 13~15 | 야간 감마 보정 | 어두운 환경 |
| 16~18 | 원본 + 그레이스케일 변형 | 일반 조건 |

### 한글 혼동문자 교정 테이블
PaddleOCR이 한글을 숫자로 오독하는 패턴을 교정:

```python
_HANGUL_CONFUSE_MAP = {
    "2": "리",  # 리(ㄹ+ㅣ) 자획 → 숫자 2로 오독
    "7": "나",  # 나 → 7
    "4": "라",  # 라 → 4
    "0": "오",  # 오 → 0
    "3": "가",  # 가 → 3
    "1": "이",  # 이 → 1
    "5": "마",  # 마 → 5
    "6": "바",  # 바 → 6
}
```

### PlateTracker — Ghost Detection 방지
- **문제**: 차가 지나간 후에도 번호판이 화면에 잔상으로 남는 현상
- **해결**: IoU(교차비) 기반 트랙 매칭 → 미감지 즉시 트랙 만료
- **파라미터**:
  - `frame_skip_interval = 5` (매 5프레임마다 YOLO 실행)
  - `gph_ttl_frames = 15` (15프레임 내 미감지 시 제거)
  - `frames_absent >= 1` 즉시 트랙 삭제

### CRNN 교차검증
- **역할**: PaddleOCR이 읽은 한글 문자를 CRNN으로 2차 검증
- **모델**: `plate_ocr_crnn.pth` (42MB, 86 classes)
- **조건**: CRNN 신뢰도 >= 0.90 일 때만 교정 적용 (낮으면 PaddleOCR 결과 유지)
- **대상**: 한글 1자 교정 (수↔라, 다↔자 등 혼동 쌍)

### COMM-FIX 가드
구형/영업용 번호판에서 지역명(충,전,경)이 숫자로 오독되는 경우만 교정:
- 이미 유효한 신형 8자리 번호판(`123가4567`)이면 교정 스킵
- CRNN이 영업용 패턴을 확인한 경우에만 허용
